GROW WITH COUSINS - STATIC HOSTING PACKAGE

1. Extract the ZIP into a new folder. Open index.html in a browser.
   No server, installation or build is needed. Keep the files together.
2. Upload index.html, styles.css, config.js, site.js and assets/ to the
   web root for grow.cousinssubs.com. All local asset paths are relative.
3. Once HR has created its Microsoft Form, paste its RESPONDENT link into
   microsoftFormUrl in config.js. Use the https:// link, not an edit link.
   The Raise My Hand button will then open it in a new tab.
4. Until that link is entered, the button shows the coming-soon message.
   This package does not collect, store or send employee responses.
5. Before sharing, test using the access available to a restaurant employee,
   including anyone without a company Microsoft account. Confirm HR can see
   the test response. HR/IT should choose the appropriate form permissions.

The original guest-focused wording, career roles, benefits, promotion steps,
FAQs and branding are preserved. The former embedded form is replaced by a
button for the HR-managed form. Questions for recreating it are included in
MICROSOFT-FORM-QUESTIONS.txt. No ChatGPT hosting or external code/CDNs are
required. Internet access will be needed when opening the Microsoft Form.
